# Project overview

## What is commondev?

`commondev` — short for **Commonwealth of Developers** — is an open-source
AI coding agent being built as a community effort.

The premise is simple: a coding agent shouldn't be a single vendor's
closed product. It should be something transparent, extensible, and
genuinely owned by the people who use it. That's the "commonwealth" —
a shared foundation that anyone can inspect, modify, and improve.

## Where we are now

The project is in **research / pre-architect** phase. The core question on
the table is:

> Build from scratch, or build on top of the [Pi SDK](https://github.com/pi-coding-agent/pi)?

No decision has been made yet. Both paths are being investigated, and the
reasoning will be documented publicly as it happens.
